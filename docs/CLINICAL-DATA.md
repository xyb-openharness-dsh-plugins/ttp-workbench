## 事件口径

- 发作：一次急性 TTP 发作（入院/置换启动，按医生原文日期）；未知日期显式 null
- 缓解开始：医生原文记录；无记录不推断
- 血浆置换：逐次记录（日期、次数序号、通路备注可私密）
- 用药：糖皮质激素/利妥昔单抗/卡普赛珠单抗等按医生原文，剂量照抄不做建议
