# 差异化矩阵（防换名复用）

> 版本 v0.1.0-draft.1（2026-11-03）。对照对象：家族已有仓（breast-cancer/aml/behcet 等）与移植样板 cervical-workbench。
> 全部为假设场景（0 访谈）；每条验收必须出数字或截图，不接受「看过了」。

## 与家族重名率自查

一级导航草案（7 条）：病程总览 / 我的化验 / 血浆置换 / 治疗与用药 / 复诊准备 / 就医与紧急 / 我的资料。
与 breast-cancer 一级（含分期/疗效应答/标志物）重名 1 条（我的化验-目录语义）；与 behcet 一级重名 3 条（时间线/化验/资料语义近似）。
实测方法：一级页名逐词比对两样板 prototypes/v0.2 导航数组，M1 末尾出计数。目标 ≤70%，当前估算 43%（3/7），M1 出实测数。

## 差异化条目（场景 → 功能 → 怎么验收）

1. 复发先兆就诊准备：缓解期新发瘀斑/牙龈出血，想给医生看「距上次发作多久、血小板和 LDH 怎么走」 → 发作—缓解时间线 + 血小板/LDH 趋势图联动 → A/B 档案切换后时间线与趋势同步且不串档（无头断言，输出两套记录数）。
2. 血浆置换按次整理：一疗程十几次置换，出院后记不清次数与日期 → 治疗折叠卡按「一次发作」分组，置换逐次记录 + 次数统计 → 折叠收/展两态截图；统计数与演示数据逐条对账相等。
3. 化验可比组：ADAMTS13 各院方法/单位不同，患者不知能否比较 → 化验条目带方法/单位/机构标注，跨方法不合并、不做差、不连线 → 跨方法合成数据断言趋势断线（出 path 数对比）。
4. 紧急行动卡：出现先兆不知何时就医 → 只呈现医生已确认的行动计划原话；无确认时空态引导「问你的医生」 → 禁词检查器 0 命中（不出现「你已复发/可能复发」），空态截图。
5. 置换血管通路与耗材自记（患者记录等待时长/穿刺情况，医生任务不冒充患者需求） → 每次置换可附 1 行体感备注 → 私密标记三出口过滤断言。
