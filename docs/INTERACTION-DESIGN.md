## 关键交互路径（草案，M1 逐条补产物与回首页）

- IP-T01 病程总览：顶栏档案切换 → 时间线（发作—缓解区间带）→ 点发作块 → 折叠卡展开本次发作详情 → 回总览
- IP-T02 化验：我的化验 → 选指标 → 趋势图（可比组内连线）→ 点数据点开原始来源 → 关闭焦点恢复
- IP-T03 置换：血浆置换 → 按发作分组折叠卡 → 展开逐次置换 → 计次统计卡
- IP-T04 复诊准备：复诊准备 → 勾选要带的指标/问题 → 生成一页预览 → 导出
- IP-T05 紧急：就医与紧急 → 行动计划卡（原话或空态）→ 一键展示摘要页
- IP-T06 录入：任意页 ⋯ 更多 → 手工录入（≤6 字段，数字用数字键盘组件）→ 写入事实层新版本（无裸删除）
