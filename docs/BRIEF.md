# 需求起点

来源：初始化配置。用户、场景和流程是有效的SPEC互动素材；继承会话中已有明确确认，其余不能仅因配置通过校验就当成设计定稿或研究验证。

目标用户：血栓性血小板减少性紫癜（TTP，含免疫性 iTTP 与遗传性 Upshaw-Schulman 综合征）成年患者与授权代记者，覆盖急性发作期出院后、缓解期长期随访与复发监测阶段；不覆盖未确诊人群的鉴别诊断

场景：把散落在急诊病历、血浆置换记录单、化验单和出院小结里的信息整理成发作—缓解时间线，重点照看血浆置换疗程次数、血小板/LDH/ADAMTS13 趋势（跨方法不合并）、缓解期复发监测与复诊准备

核心流程：
1. 建立档案并导入或手工录入最近一次发作的出院资料与置换记录
2. 在发作—缓解时间线上记录化验、置换与用药事件，缓解期按周期录入监测化验
3. 带着整理好的趋势图、置换次数汇总和问题清单去复诊

完成结果：复诊前能在一页里说清距上次发作多久、最近血小板和 LDH 怎么走、做过几次血浆置换、有哪些问题要问医生

初始布局选择：business-first
