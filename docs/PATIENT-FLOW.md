# 患者流程（信息维度视角）

> 版本 v0.1.0-draft.1（2026-11-03）。假设流程，无访谈依据；只做信息整理，不做诊断与处置建议。

## 主循环（缓解期）

录入复查化验 → 看趋势与「距上次发作 N 天」 → 复诊前整理问题清单与趋势页 → 复诊带回新医嘱原文 → 存档报告原件。

## 急性支线（发作）

新发症状 → 打开紧急行动卡（医生行动计划原话或空态） → 就医 → 出院后录入本次发作（日期、置换次数、出院化验） → 回到主循环。

## 首次使用

两套合成示例档案（A 刚确诊记录少 / B 多年随访记录多）→ 「新建我的档案」空态起步，每步给下一步按钮，不只写「暂无数据」。

## 明确不做

鉴别诊断、用药剂量计算、复发概率判断、指标自动判读（分级徽章只写「对照 <指南/共识> · 待核」且需临床审核后才启用）。
